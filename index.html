Grid

Cell ×
Offset ,
Resolution ×

Cell is the size of one art pixel in source pixels. Offset is where the first grid line starts.

Auto detects the grid and changes the values only when it’s confident.

Shift + drag on the source moves the grid. Arrow keys nudge a value by 0.01, or 0.1 with Shift.

Snap lines to edges helps when the pixel size drifts across the image.

Palette

Colors
Result palette

As is keeps the downscaled colors. Auto builds a palette from the image. Library maps colors to a built-in palette or to your own .hex or .gpl file (you can drop it onto the window).

Suggest color count is a starting point: it works well for sprites and often goes too low on detailed scenes.

The swatches show the colors actually used, and Save .hex exports them.

Dithering

Strength, %

Mixes two palette colors where an in-between shade is missing. Needs a palette.

Bayer gives a steady pattern that suits animation. Floyd-Steinberg is smoother but shimmers between frames. Most sprites look better without dithering.

Cleanup

Padding, px

Stray pixels are lone specks left by JPEG noise. Alpha holes are transparent gaps inside a sprite.

If you use an outline, keep Padding at 1 px or more so it has room.

Outline

Neighbors
Color
Darken, %

Outline adds a 1 px border around the sprite, by default in its darkest color, so the palette doesn’t grow.

Dark edges darkens the sprite’s own edge pixels instead: the size stays the same and small details don’t merge.

Pixel scale

About ixpix

Turns AI-generated “pixel art” into true 1:1 pixel art with a transparent background, ready to use as game assets.

Everything runs in your browser: images are never uploaded anywhere.

Troubleshooting

grid not found
enter the cell size manually or set the result resolution
background not removed
use “Flood” instead of “Chroma key”, add points with the eyedropper, raise the ΔE tolerance
light fringe
raise “Defringe, ΔE”
frames merged
lower “Gap” under “Sprites”
